How this system works

  1. A sensor would measure temperature and humidity. In this starter project, the API simulates these values.
  2. The FastAPI backend receives a reading and compares it with the configured limits.
  3. The dashboard calls the API and shows the latest values and alerts.
  4. Tests check that the API and alert logic behave as expected.
